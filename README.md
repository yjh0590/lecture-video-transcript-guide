# 강의 영상 대본화 가이드 — 웹 버전

강의 영상을 브라우저 안에서 MP3로 변환하고, 클로바노트 대본 제작과 ChatGPT 학습까지 6단계로 안내하는 정적 웹사이트입니다.

## 주요 특징

- 파일을 서버에 업로드하지 않는 브라우저 내부 변환
- MP4를 음성 인식용 64kbps 모노 MP3로 변환
- 클로바노트, PRPT, ChatGPT 연결
- TXT 대본 선택과 학습 프롬프트 복사
- 처음으로 돌아가기 및 단계별 진행 표시
- 데스크톱과 모바일 반응형 화면
- GitHub Pages 배포 지원

## 로컬 실행

```bash
npm install
npm run dev
```

기존 버전에서 `변환 도구를 불러오는 중` 상태가 계속되었다면 실행 중인 창을 종료한 뒤 새 버전을 별도 폴더에 풀어 다시 실행하세요. 개발 서버는 FFmpeg 작업자 파일이 잘못 묶이지 않도록 관련 라이브러리를 사전 묶음 대상에서 제외합니다.

Vite에서 실행되는 모듈 작업자와 형식을 맞추기 위해 `public/ffmpeg`에는 ESM용 `ffmpeg-core.js`와 WebAssembly 파일을 포함합니다.

## GitHub Pages용 빌드

```bash
npm install
npm run build
```

생성된 `dist` 폴더를 GitHub Pages에 배포하면 됩니다. Vite의 상대 경로 설정을 사용하므로 프로젝트 저장소 주소와 사용자 도메인 모두에서 동작합니다.

`main` 브랜치에 올리면 자동으로 빌드·배포하는 GitHub Actions 파일이 포함되어 있습니다. 저장소의 `Settings → Pages → Source`에서 `GitHub Actions`를 선택하세요. 사용자 도메인은 `study.oddz.click`로 준비되어 있습니다.

## 주의사항

- 변환은 브라우저 메모리를 사용하므로 긴 강의나 대용량 영상은 느리거나 중단될 수 있습니다.
- 저사양 기기와 모바일에서는 Windows 앱 사용을 권장합니다.
- 학교에서 허용한 강의만 내려받고 개인 학습 범위에서 사용하세요.
